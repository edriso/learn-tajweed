> هذه الصفحة للمراجعة السريعة، لا للتعلُّم الأوّل. إن مرّ بك حكمٌ لا تفهمه فارجِع إلى درسه.

## أحكام النون الساكنة والتنوين

| الحكم | الحروف | العدد | ماذا تفعل |
| --- | --- | --- | --- |
| **إظهار حلقيّ** | ء ه ع ح غ خ | ٦ | انطق النون واضحةً بلا غنّةٍ زائدة |
| **إدغام بغنّة** | ي ن م و | ٤ | شدِّد الحرف، وأبقِ الغنّة حركتين |
| **إدغام بغير غنّة** | ل ر | ٢ | شدِّد الحرف، ولا غنّة |
| **إقلاب** | ب | ١ | اقلِب النون ميمًا مخفاةً بغنّة |
| **إخفاء حقيقيّ** | الباقي | ١٥ | لا تلمس اللسان، وغنّةٌ حركتين |

**المجاميع:** إظهار «أَخِي هَاكَ عِلْمًا حَازَهُ غَيْرُ خَاسِرِ» · إدغام «يَرْمَلُون» (وبغنّة منها «يَنْمُو»).

**الإظهار المطلق:** أربع كلماتٍ فقط، وقعت فيها النون والحرف في كلمةٍ واحدة: الدُّنْيَا · بُنْيَان · صِنْوَان (الرعد) · قِنْوَان (الأنعام).

## أحكام الميم الساكنة

| الحكم | الحرف | ماذا تفعل |
| --- | --- | --- |
| **إخفاء شفويّ** | ب | تلامسٌ رفيقٌ للشفتين مع غنّةٍ حركتين |
| **إدغام شفويّ** | م | ميمٌ مشدَّدةٌ بغنّةٍ حركتين |
| **إظهار شفويّ** | الباقي (٢٦) | ميمٌ واضحةٌ بلا غنّةٍ زائدة |

**احذَر:** الميم قبل **الفاء والواو** تُظهَر إظهارًا تامًّا.

## الغنّة

كلّ **نونٍ أو ميمٍ مشدَّدة**: غنّةٌ حركتان وجوبًا. وهي أكمل الغنّات، فاجعلها مقياسك.

## اللام والراء

**لام التعريف:** سكونٌ على اللام ← قمريّة. شدّةٌ على ما بعدها ← شمسيّة.
القمريّة تُجمَع في «ابْغِ حَجَّكَ وَخَفْ عَقِيمَهُ».

**لفظ الجلالة:** بعد فتحةٍ أو ضمّة ← تفخيم. بعد كسرة ← ترقيق.

**الراء:**

| تُفخَّم | تُرقَّق |
| --- | --- |
| مفتوحة · مضمومة | مكسورة |
| ساكنة بعد فتحٍ أو ضمّ | ساكنة بعد كسرٍ أصليّ |
| ساكنة بعد كسرٍ عارض (همزة وصل) | ساكنةٌ للوقف بعد ياءٍ ساكنة |
| ساكنة بعد كسرٍ أصليّ وبعدها حرف استعلاءٍ غير مكسور | ساكنةٌ للوقف بعد كسر |

## التفخيم والترقيق

**حروف الاستعلاء السبعة:** «خُصَّ ضَغْطٍ قِظْ» مفخَّمةٌ دائمًا.
**الأربعة المطبَقة:** ص ض ط ظ، وهي أقواها.
**الألف** تتبع ما قبلها. **بقيّة الحروف** مرقَّقةٌ دائمًا.

**مراتب التفخيم:** مفتوحٌ بعده ألف ← مفتوح ← مضموم ← ساكن ← مكسور.

## القلقلة

**حروفها:** «قُطْبُ جَدٍّ» (ق ط ب ج د). **شرطها:** السكون.

| المرتبة | الحال |
| --- | --- |
| صغرى | ساكنٌ في وسط الكلمة |
| وسطى | ساكنٌ في آخرها وقفًا، غير مشدَّد |
| كبرى | ساكنٌ في آخرها وقفًا، مشدَّد |

## المدود

| النوع | السبب | المقدار |
| --- | --- | --- |
| **طبيعيّ** | لا همز ولا سكون | ٢ |
| **بدل** | همزةٌ **قبل** المدّ | ٢ |
| **عِوَض** | وقفٌ على تنوين فتح | ٢ |
| **صلة صغرى** | هاء الضمير بين متحرّكين | ٢ |
| **واجب متّصل** | همزةٌ بعد المدّ، في كلمة | ٤ أو ٥ |
| **جائز منفصل** | همزةٌ بعد المدّ، في كلمتين | ٤ أو ٥ |
| **صلة كبرى** | هاء الضمير ثمّ همزة قطع | ٤ أو ٥ |
| **عارض للسكون** | سكونٌ بسبب الوقف | ٢ أو ٤ أو ٦ |
| **لِين** | واوٌ أو ياءٌ ساكنة بعد فتحة، ثمّ وقف | ٢ أو ٤ أو ٦ |
| **لازم** | سكونٌ أصليّ | ٦ وجوبًا |

**حروف المدّ:** «نُوحِيهَا». **قاعدة التسوية:** لا يكون المنفصل أطول من المتّصل.

**الفواتح:** «نَقَصَ عَسَلُكُمْ» ← ٦ حركات · «حَيٌّ طَهُرَ» ← ٢ · **ألف** ← لا مدّ.

## التقاء الحرفين

| | التعريف | الحكم عند حفص |
| --- | --- | --- |
| **متماثلان** | اتّفقا مخرجًا وصفة | إدغامٌ وجوبًا |
| **متجانسان** | اتّفقا مخرجًا واختلفا صفة | إدغامٌ في مواضعَ معدودة |
| **متقاربان** | تقاربا ولم يتّحدا | إظهارٌ إلّا في موضعين |
| **متباعدان** | تباعدا | إظهارٌ باتّفاق |

**ولا إدغام كبير في رواية حفص.**

## الوقف

| الرمز | معناه |
| --- | --- |
| **مـ** | وقفٌ لازم |
| **لا** | لا وقف |
| **قلى** | الوقف أولى |
| **صلى** | الوصل أولى |
| **ج** | وقفٌ جائز |
| **∴ ∴** | معانقة، قِف على أحدهما |

**كيفيّة الوقف:** السكون في كلّ حال · الرَّوم للمضموم والمكسور · الإشمام للمضموم وحده.
